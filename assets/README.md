# Game assets

Runtime artwork and audio are embedded in js/art.js, js/musicdata.js, js/sfxdata.js, and js/vox.js. The room and interface also use procedural Canvas and CSS rendering.

Standalone WebP assets are retained alongside the embedded runtime versions. Original recordings, old takes, source images, and asset-generation tools stay local. They are not needed to run the game or build the single-file itch.io release.

The optional external-image loader in js/assets.js is disabled in the current version. See the root README for the AI disclosure and rights notice.
